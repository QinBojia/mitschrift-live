﻿随堂字幕（Mitschrift Live）使用说明
==================================

实时识别电脑里播放的声音（显示为"对方"）和你的麦克风（显示为"我"），
显示字幕和翻译。支持德语、英语、中文。
（以前叫 Live Capture，改名后设置和用法都不变。）

一、安装
1. 双击 MitschriftLive-...-Setup.exe。
   如果弹出"Windows 已保护你的电脑"：点"更多信息"→"仍要运行"。
   （这是因为程序没有购买代码签名证书，不是病毒。）
2. 按提示点"下一步"即可。程序装在你自己的用户目录里，不需要管理员权限。
3. 装好后，桌面和开始菜单里会有"随堂字幕"。
   已经装过的话，直接运行 MitschriftLive-...-Update.exe 更新就行，不用重装。

二、使用
- 打开后点左上角的"开始"。第一次打开要加载模型，等几秒钟。
  NPU 版第一次使用时，需要约 1 分钟为 NPU 优化模型，只有第一次需要。
- 右上角选择译文语言：中文 / English / Deutsch / 关（只显示字幕）。
- 屏幕下方的悬浮字幕条可以拖到任何位置，盖在 Zoom 上面。
  鼠标移到字幕条上，右上角会出现按钮：调字号、显示内容（原文+译文 / 仅原文 / 仅译文）、
  穿透、隐藏。
- 主窗口右上角齿轮 → 悬浮字幕：可以分别调文字和背景的不透明度。
  背景调到 0 就只剩文字浮在 Zoom 上；鼠标移上去时会暂时显示背景，方便拖动。
  拖字幕条的边缘可以改大小；拉高以后能同时看到更多前面的字幕。
- "穿透"打开后，鼠标会直接点到字幕条下面的窗口。
  按 Ctrl+Alt+L 可以关闭穿透（如果这个快捷键被占用，会换成
  Ctrl+Alt+C 或 Ctrl+Alt+F12，具体是哪个可以在设置里看到）。
- 点主窗口右上角的 ✕ 不会退出，程序会缩到屏幕右下角的托盘继续运行。
  要退出：右键托盘里的蓝色图标 →"退出随堂字幕"。
- 不戴耳机（外放）也可以用，程序会自动消除回声；戴耳机效果最好。
- 点"● 录音"会把双方的声音和字幕（含翻译）保存到"文档\Mitschrift Live"
  （保存位置可以在 设置 → 录音 里改）
  （改名前的录音还在"文档\Live Capture"）。
  点录音之前的字幕也会一起存进去；中途暂停不会把录音拆开，再点一次"● 录音"才结束。
- 主窗口底部的"清空"会清掉主窗口和悬浮字幕条里的字幕（已经录下的不受影响）。

三、电脑要求
- Windows 11，64 位。
- CPU 建议 4 核 8 线程以上。电脑较慢时，说话过程中字幕刷新会自动变慢，
  但每句话说完后的字幕不受影响。
- NPU 版需要 Intel Core Ultra 处理器。没有可用的 NPU（例如没装 NPU 驱动）时，
  会自动改用 CPU 识别。
- AMD 版用核显（Radeon）识别。没有可用的核显时会自动改用 CPU 识别。

四、出问题时
- 日志文件在：C:\Users\你的用户名\.livecapture\logs\live-capture.log
  把它发给我就行。
- 翻译用的是我的 DeepSeek 账户，请不要把这个程序再转发给别人。
